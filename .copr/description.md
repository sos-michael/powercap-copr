PowerCap provides command-line tools and a C library for Linux power capping,
including Intel RAPL. Packages include powercap-info, powercap-set, rapl-info,
rapl-set, and libpowercap. Development headers are available in powercap-devel.

This unofficial repository tracks upstream master at
https://github.com/powercap/powercap. GitHub Actions checks for changes every
Monday and builds new revisions for the configured Fedora and EPEL releases.
Unchanged successful revisions are skipped; failed builds are retried.

Packaging and automation: https://github.com/sos-michael/powercap-copr
